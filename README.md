# Alaa Hani — Video Editor Portfolio

A responsive, single-page portfolio website built with plain HTML, CSS, and JavaScript. No build tools are required.

## Preview locally
Open `index.html` in a browser.

## Before publishing
1. In `index.html`, replace `YOUR_EMAIL@example.com` with your professional email address.
2. Check the Instagram and Google Drive links.
3. Replace the sample project cards with real work. The Vertx card currently links to the supplied Google Drive folder.
4. The visual backgrounds are CSS artwork, not screenshots of actual client projects. Keep the disclaimer or replace the sample projects with work you are allowed to show.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account at https://github.com/
2. Click **New repository**.
3. Name it `YOUR-USERNAME.github.io` (replace with your GitHub username), set it to **Public**, and create it.
4. Click **Add file → Upload files**.
5. Upload `index.html`, `style.css`, `script.js`, and `README.md` from this folder (not the containing folder itself).
6. Click **Commit changes**.
7. Open the repository's **Settings → Pages**.
8. Under **Build and deployment**, select **Deploy from a branch**, choose branch `main` and folder `/(root)`, then click **Save**.
9. Wait a few minutes and open `https://YOUR-USERNAME.github.io/`.

GitHub Pages sites are public. Do not put passwords, private client assets, or sensitive information in the repository.
